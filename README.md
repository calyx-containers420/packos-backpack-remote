# packOS backpack remote

Phone remote for the packOS signage kiosk. The source of truth is `demo-studio/kiosk-remote/index.html` in
`calyx-containers420/packOS-ABM` (see `demo-studio/SIGNAGE.md`, "Phone remote"); this repository only serves a copy
through GitHub Pages. The page holds no secrets: the channel name is entered on the phone and stays there.
