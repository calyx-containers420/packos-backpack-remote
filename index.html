Setup

Set the kiosk browser's start page to this address, so the backpack listens on the same channel:

file:///sdcard/packos-kiosk/index.html?remote=…

Anyone who knows the channel can change what the screen shows (only these buttons, nothing else). Keep it private; make a new one after the show.

The free relay allows 250 messages a day per internet connection, shared by this phone and the backpack on its hotspot. Each tap uses about two; the backpack sends nothing on its own.
